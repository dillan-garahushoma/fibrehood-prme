# Awesome DESIGN.md - Design Systems Collection

A `DESIGN.md` file is a plain-text markdown design system document that AI agents read to generate consistent, high-quality UI matching real-world design specifications.

## Overview

This skill provides direct access to 70+ curated `DESIGN.md` design system files extracted from developer-focused tools, AI platforms, fintech, automotive, consumer tech, and SaaS applications.

## How to Use DESIGN.md Specs

1. **Select a Design System**: Browse the category index below or look up a brand in `./design-md/<brand-name>/DESIGN.md`.
2. **Read the Design Spec**: Read `./design-md/<brand-name>/DESIGN.md` to extract color tokens, typography scales, component stylings, visual atmosphere, shadows, micro-interactions, and anti-patterns.
3. **Apply to UI Generation**: Use the extracted tokens and principles when creating or editing frontend components, pages, or Tailwind/CSS themes.
4. **Project Root Placement**: Optionally copy `./design-md/<brand-name>/DESIGN.md` into the user's project root as `DESIGN.md` so future agent runs reference it.
